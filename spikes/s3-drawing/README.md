# S3. Рисунок на кадре

Из корня репозитория подготовить тестовое видео и открыть стенд через сервер с поддержкой HTTP Range.

```sh
(cd spikes/s2-player-seek && ONLY=cfr30-g30 ./gen-test-videos.sh)
npx --yes vite@8.3.8 spikes --host 127.0.0.1 --port 8875
```

Открыть http://127.0.0.1:8875/s3-drawing/. На кадре 45 нарисовать линию от первого белого блока слева вверху. Нажать «Сохранить». Перейти на кадр 46 и вернуться. Изменить размер окна и включить полный экран. После обновления страницы выбрать кадр 45 и открыть сохранённый рисунок отдельно в режимах «штрихи» и «PNG». В режиме штрихов можно продолжить рисовать. Цвет и ширина задаются до начала линии. «Очистить» очищает слой, «Сохранить» записывает его для выбранного кадра и версии.

В спайке используется локальное хранилище браузера. В продукте источником данных остаётся сервер (D-016). Скрипт измерения мышью, сохранения, проверки геометрии и маски рисунка находится в соседнем стенде S4. После установки его зависимостей:

```sh
cd spikes/s4-shared-player
node verify.mjs chrome http://127.0.0.1:8875/s3-drawing/
```

Числа и ограничения измерений — в разделе S3 документа `docs/04-spikes.md`.
