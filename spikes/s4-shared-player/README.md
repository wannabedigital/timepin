# S4. Общий плеер в Electron и браузере

Одноразовый npm workspace. Один React-компонент в `packages/ui` использует слой рисования S3. Vite и TypeScript собирают один интерфейс для обеих оболочек.

Нужны готовые прокси S1 и видео S2. Пути перечислены в `fixtures.mjs`. Если файлов нет, положить оригиналы Big Buck Bunny и iPhone 13 в `spikes/s1-ffmpeg-proxy/media/` по инструкции в корневом README. Из корня репозитория выполнить:

```sh
(cd spikes/s1-ffmpeg-proxy && ./make-proxies-real.sh media/real-bbb-1080p30-10min.mp4 && ./hdr-compare.sh media/real-iphone13pro-4k-dv-hlg-60.mov)
(cd spikes/s2-player-seek && ONLY=cfr30-g30 ./gen-test-videos.sh)
```

Из каталога `spikes/s4-shared-player`:

```sh
npm ci
npm run build
npm run desktop
```

Electron загружает собранный интерфейс и локальные видео по схеме `timepin://player/`. Список разрешённых файлов формирует основной процесс. Для HTTP-версии запустить `npm run web` и открыть выведенный адрес. Копии медиа для web и сборка игнорируются Git.

## Проверка общего плеера

При запущенном web-сервере и установленном Google Chrome:

```sh
node verify.mjs chrome http://127.0.0.1:5173/
node verify.mjs electron
```

Проверки используют отдельные профили. Скрипт сравнивает зашитый номер кадра с ожидаемым, рисует мышью, проверяет полный экран, шаг с клавиатуры, восстановление рисунка, геометрию и совпадение масок. Для повтора Windows-прогона после сборки запустить `node verify.mjs electron` из каталога стенда. Для Electron веб-сервер не требуется.

В Safari и Firefox открыть `/check.html` на web-сервере. Страница выведет JSON: сведения о звуковой дорожке, воспроизведение HLG и SDR, фактический номер кадра, возврат к сохранённому штриху, ошибку геометрии и обработку стрелки. Она использует заранее заданный штрих и программное событие клавиатуры. Полноэкранный режим и рисование мышью в этих двух браузерах можно проверить вручную на главной странице.
