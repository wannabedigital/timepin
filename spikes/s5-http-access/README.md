# S5. Перемотка и гостевой доступ по HTTP

В корне репозитория на Mac:

```sh
python3 spikes/s5-http-access/run.py
```

На Windows в PowerShell после обновления репозитория:

```powershell
py -3 spikes/s5-http-access/run.py
```

Нужны Python с venv и pip (на Mac проверен 3.9.6), Node.js с npm (22.12+), установленный Google Chrome или на Windows Microsoft Edge. Для первого запуска нужен интернет. Используется готовый 720p-прокси Big Buck Bunny из S1. Если прокси отсутствует, скрипт собирает его через FFmpeg из `spikes/s1-ffmpeg-proxy/media/real-bbb-1080p30-10min.mp4`. Оригинал указан в корневом README. Для зависимостей, тестовых загрузок и временного профиля оставить не менее 1,5 ГБ свободного места.

Скрипт подготавливает venv в `out/`, использует Playwright и Electron из зафиксированных зависимостей S4, при необходимости выполняет там `npm ci`. Поднимает FastAPI и отдельный приёмник Referer на свободных портах 127.0.0.1. Синтетический гость вводит имя и открывает видео по ссылке с токеном во фрагменте. Проверяются три варианта дальнейшего доступа к видео.

Код 0 и строка `PASS <путь>` означают, что прошли все проверки:

- потоковая загрузка, SHA-256, прогресс отправки, граница 192 МиБ и отказ при превышении на байт;
- в браузере и Electron по три перемотки в середину файла с показом кадров, ответами 206 и проверкой объёма передачи;
- новый запрос после отзыва и истечения приглашения, отдельное истечение подписи при действующем приглашении;
- отсутствие секретов в проверяемых журналах, отсутствие Referer на другом origin и положительный контроль с явной передачей origin.

`out/s5-*.json` содержит ОС, версии клиентов, объём и время загрузки, смещения Range, переданные байты и результаты проверок. Каждый успешный запуск получает отдельный отчёт. Временный сервер, гостевые сессии, копия прокси и профиль Electron существуют только во время прогона. Итоговые замеры ведутся в разделе S5 документа `docs/04-spikes.md`.

Для повторяемой проверки перемотки отдача каждого ответа ограничена примерно 4 МиБ/с. Счётчик суммирует тело ответов, переданное сервером в ASGI до отключения. Во время сравнения способов доступа кеш выключен. Лимит загрузки и сроки жизни тестовые. В продукте понадобятся HTTPS и отдельная проверка журналов reverse proxy.
