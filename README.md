# Timepin

Программный комплекс для асинхронного согласования правок видео с привязкой к таймкоду: desktop-приложение для монтажёра и веб-клиент для гостей и рецензентов. Монтажёр загружает версии видео в раунды, рецензент оставляет замечания на конкретном моменте, монтажёр выполняет правки и выпускает новый раунд с незакрытыми замечаниями.

Проект выполняется как выпускная квалификационная работа по направлению «Разработка IT-систем и мультимедийных приложений».

## Статус проекта

Стадия 1 по ГОСТ Р 59793-2021 — формирование требований (обследование, показатели, отчёт). Параллельно идут технические проверки (spike, этап 2.2): S1 (FFmpeg-прокси) проверена на macOS, осталась проверка на Windows. Продуктовый код не написан: по плану разработка начинается на этапе 6.2, после технического проекта. Тема согласована с научным руководителем. Решения записаны в `docs/decisions.md`: часть из них пока гипотезы, но по ним ведётся работа.

Актуальный список «сделано / дальше» — в `docs/03-roadmap.md`, раздел «Где я сейчас».

## Быстрый старт на новой машине

Нужно для технических проверок (`spikes/`). Для работы только с документацией хватит Git и редактора.

| Что | Зачем | Установка |
|---|---|---|
| Git (на Windows — Git for Windows, в нём есть Git Bash) | Репозиторий и запуск `.sh`-скриптов | macOS: `brew install git`; Windows: git-scm.com |
| Node.js (на macOS проверено на v26.10.0) | Скрипты `.mjs` и запуск FFmpeg из Node | nodejs.org или `brew install node` |
| FFmpeg и ffprobe, **полная сборка** (libx264, libx265, libvmaf, zscale, drawtext) | Создание прокси, замеры, HDR | macOS: `brew install ffmpeg ffmpeg-full` (полная сборка лежит в `/opt/homebrew/opt/ffmpeg-full/bin/`); Windows: полная сборка, например `winget install Gyan.FFmpeg` (не проверено, возможности сборки показывает `env-check.mjs`) |
| Claude Code | Работа с проектом | см. документацию Claude Code |

Порядок:

1. Получить репозиторий: `git clone git@github.com:wannabedigital/timepin.git` (нужен SSH-ключ, добавленный в GitHub).
2. Проверить окружение: `node spikes/s1-ffmpeg-proxy/env-check.mjs`. Скрипт показывает версию FFmpeg и какие кодеры и фильтры есть. Вывод вставить в `docs/04-spikes.md`, если это новая ОС.
3. Положить тестовые видео в `spikes/s1-ffmpeg-proxy/media/` (таблица ниже). Папки `media/` и `out/` в репозиторий не попадают.
4. Скрипты `.sh` запускать из Git Bash (на Windows) или из терминала (macOS, Linux). Порядок команд — в `spikes/s1-ffmpeg-proxy/README.md`.
5. Результаты записывать в `docs/04-spikes.md` (таблицы и журнал находок). Не заводить отдельных файлов с итогами.
6. Запустить `claude` в корне репозитория: `CLAUDE.md` читается автоматически и содержит контекст проекта и порядок начала сессии.

### Тестовые видео

Все ролики из открытого доступа. В ВКР и на скриншотах указывать источник.

| Имя файла в `media/` | Что это | Где взять |
|---|---|---|
| `real-bbb-1080p30-10min.mp4` | Big Buck Bunny, `bbb_sunflower_1080p_30fps_normal.mp4`, 1080p, 30 к/с, около 10 минут, лицензия CC BY (Blender Foundation) | Раздел «Big Buck Bunny» страницы Kodi Samples (kodi.wiki/view/Samples) или сайт Blender Foundation |
| `real-iphone13pro-4k-dv-hlg-60.mov` | Съёмка iPhone 13 Pro, 4K, HDR (HLG, Dolby Vision), 60 к/с, около 20 с | Kodi Samples: «Dolby Vision w/embedded HLG HEVC 60fps (MOV, Photography Blog's iPhone 13 Pro raw 4K footage)» |
| `real-iphone6s-4k-h264-2997.mov` | Съёмка iPhone 6S, 4K, H.264, 29,97 к/с, около 19 с | Kodi Samples: «H.264 29.97fps, 51Mbps (MOV, @ht2tweak's iPhone 6S raw 4K footage)» |

Синтетические исходники (`src-*.mp4`) создаёт `gen-sources.sh`, скачивать их не нужно.

## Структура репозитория

```

  s1-ffmpeg-proxy/   скрипты, README и env-check.mjs; media/ и out/ в git не хранятся
apps/        приложение (появится на этапе 6.2)
  desktop/   Electron + React, монтажёр
  web/       Vite + React, гости и рецензенты по ссылке
  server/    FastAPI
packages/
  ui/        общие React-компоненты плеера и комментариев
  api-client/ клиент к серверу
```
